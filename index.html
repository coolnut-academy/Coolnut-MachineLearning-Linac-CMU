Research Options

1. Virtual Diagnostics

RECOMMENDED
(เหมาะที่สุดสำหรับช่วงที่เครื่องยังรันไม่สมบูรณ์)
โจทย์ทางฟิสิกส์:

ปกติการวัด Transverse Emittance ต้องใช้เวลาสแกน และเป็นการรบกวนลำแสง (Destructive) ทำให้ไม่ทราบค่าคุณภาพลำแสงแบบ Real-time

แนวทางวิจัย:

สร้างแบบจำลองคณิตศาสตร์ที่เรียนรู้จาก ข้อมูล Simulation (ASTRA) เพื่อหาความสัมพันธ์ระหว่างค่า Setting ของเครื่อง กับหน้าตัดของลำอิเล็กตรอน (Phase Space) ที่ปลายทาง

สิ่งที่ได้:

เครื่องมือที่สามารถ "ทำนาย" ค่า Emittance และรูปทรงของลำแสงได้ทันทีโดยไม่ต้องเอา Screen ไปขวางลำแสงจริง

Reference (SLAC): ทีมวิจัยใช้ข้อมูล Simulation ร่วมกับข้อมูลจริง มาเทรนโมเดลเพื่อทำนายหน้าตาของ Phase Space ได้ทุกช็อต
Read SLAC Paper

2. Optimization

(เหมาะสำหรับช่วยลดภาระการจูนเครื่อง)
โจทย์ทางฟิสิกส์:

การปรับค่า RF/Magnet เพื่อให้ได้ Emittance ต่ำที่สุด เป็นปัญหาระบบหลายตัวแปร (Multivariable Problem) ที่ซับซ้อนและใช้เวลาจูนนาน

แนวทางวิจัย:

พัฒนาระบบค้นหาจุดทำงาน (Operating Point) ที่ดีที่สุด โดยใช้ Bayesian Optimization เรียนรู้แนวโน้มเพื่อแนะนำว่าควรปรับค่า Magnet ตัวไหน เท่าไหร่ จึงจะได้ Target Parameter ที่ต้องการ

สิ่งที่ได้:

ช่วยลดเวลา Commissioning และช่วยให้น้องๆ จูนเครื่องเข้าสู่สภาวะที่ลำแสงมีคุณภาพดีที่สุดได้รวดเร็วขึ้น

Reference (KEK): ใช้ ML ช่วยจูนค่าแม่เหล็กและ RF เพื่อเพิ่มประจุและลดค่า Emittance ได้เร็วกว่าและแม่นยำกว่าการจูนด้วยมือ
Read KEK Paper

3. Anomaly Detection

(เหมาะสำหรับงานดูแลระบบในระยะยาว)
โจทย์ทางฟิสิกส์:

เครื่องเร่งอนุภาคมักมีความผันผวน (Jitter) ของสัญญาณ RF หรืออุณหภูมิ ซึ่งส่งผลต่อความนิ่งของตำแหน่งและพลังงานของลำอิเล็กตรอน

แนวทางวิจัย:

วิเคราะห์ข้อมูลย้อนหลัง (BPM, RF) เพื่อเรียนรู้ "พฤติกรรมปกติ" และแจ้งเตือนเมื่อสัญญาณเริ่มมีแนวโน้มเบี่ยงเบนออกไป โดยใช้ LSTM Deep Learning

สิ่งที่ได้:

ระบบ Monitoring แจ้งเตือนความผิดปกติ Hardware ล่วงหน้า ช่วยป้องกันความเสียหายและวิเคราะห์สาเหตุปัญหาได้แม่นยำ

Reference (JLab): ใช้ Deep Learning เรียนรู้ Pattern การวิ่งของลำแสงปกติ เพื่อแจ้งเตือนเมื่อ Orbit เริ่มเบี่ยงเบนผิดปกติก่อนระบบจะ Trip
Read JLab Paper
