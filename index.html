Research Options

1. Virtual Diagnostics

RECOMMENDED
(เหมาะที่สุดสำหรับช่วงที่เครื่องยังรันไม่สมบูรณ์)
🕹️ วิธีใช้งานกราฟ (Controls)
💻 PC: คลิกซ้ายลาก (หมุน/เลื่อน)
🖱️ Zoom: หมุนลูกกลิ้งเมาส์
📱 Mobile: แตะลาก (หมุน) / จีบนิ้ว (ซูม)
Simulation: การกระจายตัวของอนุภาคใน Phase Space
$$ \hat{\varepsilon} = f_{\theta}(\vec{I}_{\text{sol}}, \phi_{\text{RF}}, \vec{B}_{\text{quad}}) $$ Predicting Emittance ($\varepsilon$) using Neural Networks
โจทย์ทางฟิสิกส์:

การวัด Emittance ปกติรบกวนลำแสง (Destructive) ทำให้ไม่ทราบค่าคุณภาพลำแสงแบบ Real-time

แนวทางวิจัย:

สร้างแบบจำลองคณิตศาสตร์เรียนรู้จาก ข้อมูล Simulation (ASTRA) เพื่อทำนาย Phase Space จากค่า Setting ของเครื่อง

Reference (SLAC): ทีมวิจัยใช้ข้อมูล Simulation ร่วมกับข้อมูลจริง มาเทรนโมเดลเพื่อทำนาย Phase Space ได้ทุกช็อต
Read SLAC Paper

2. Optimization

(เหมาะสำหรับช่วยลดภาระการจูนเครื่อง)
🕹️ วิธีใช้งานกราฟ 3D
💻 PC: คลิกซ้ายลากเพื่อหมุนมุมมอง
🖱️ Zoom: หมุนลูกกลิ้งเมาส์
📱 Mobile: แตะลากเพื่อหมุน / จีบนิ้วซูม
Simulation: พื้นผิวความคลาดเคลื่อนที่ AI กำลังค้นหาจุดต่ำสุด
$$ \vec{x}^* = \underset{\vec{x}}{\operatorname{argmin}} \ \varepsilon(\vec{x}) $$ Bayesian Optimization searching for global minimum
โจทย์ทางฟิสิกส์:

การปรับค่าให้ Emittance ต่ำที่สุด เป็นปัญหาหลายตัวแปรที่ซับซ้อน (Multivariable Problem)

แนวทางวิจัย:

ใช้ Bayesian Optimization เรียนรู้แนวโน้มเพื่อแนะนำค่า Magnet ที่ดีที่สุด (Operating Point) โดยอัตโนมัติ

Reference (KEK): ใช้ ML ช่วยจูนค่าแม่เหล็กและ RF เพื่อเพิ่มประจุและลดค่า Emittance ได้เร็วกว่ามนุษย์
Read KEK Paper

3. Anomaly Detection

(เหมาะสำหรับงานดูแลระบบในระยะยาว)
🕹️ วิธีใช้งานกราฟ
💻 PC: คลิกซ้ายลากเพื่อเลื่อน (Pan)
🖱️ Zoom: หมุนลูกกลิ้งเมาส์
📱 Mobile: แตะลากเพื่อเลื่อน / จีบนิ้วซูม
Simulation: สัญญาณ BPM และการตรวจจับความผิดปกติ (สีแดง)
$$ \text{Loss} = || S(t) - \hat{S}(t) ||^2 > \delta $$ Anomaly detected when reconstruction error > threshold
โจทย์ทางฟิสิกส์:

ความผันผวน (Jitter) ของ RF หรืออุณหภูมิ ส่งผลต่อความนิ่งของลำอิเล็กตรอนและอาจทำให้เครื่อง Trip

แนวทางวิจัย:

วิเคราะห์ข้อมูลย้อนหลัง (BPM, RF) เพื่อเรียนรู้ "พฤติกรรมปกติ" และแจ้งเตือนเมื่อสัญญาณผิดปกติโดยใช้ LSTM Deep Learning

Reference (JLab): ใช้ Deep Learning เรียนรู้ Pattern ปกติ เพื่อแจ้งเตือนก่อนที่ Orbit จะเบี่ยงเบนจนระบบตัดการทำงาน
Read JLab Paper
